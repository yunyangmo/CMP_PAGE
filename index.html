Learning Context-Aware Motion Priors for Humanoid Control

Yunyang Mo · Yi Gu · Yangchen Zhou · Hanyang Cao · Renjing Xu

Paper (arXiv)  ·  Code (coming soon)

Problem Formulation

Different reference motions may provide different suitable guidance depending on the environment context.

Abstract

Motion priors improve the naturalness and learning efficiency of physics-based humanoid control, but existing methods typically treat the reference motion distribution as task-agnostic. This can expose the policy to motions that are irrelevant to the current task context and make learning sensitive to dominant motion frequencies in the reference dataset. We introduce Context-Aware Motion Priors (CMP), a framework that learns context-motion relevance from online policy experience and uses the learned relevance to adapt the effective reference distribution of an underlying motion prior. CMP can be integrated with both adversarial and diffusion-based motion priors without constraining the policy to a fixed set of behaviors. Across five humanoid control tasks, CMP improves task performance and sample efficiency, learns meaningful context-motion compatibility, and remains robust to heterogeneous and imbalanced reference motion data.

Our insight

Use contrastive learning for context–motion compatibility.
